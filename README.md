# Fortune Cookies for Machines

A tiny Python program that writes a single fortune-cookie line for a machine mind: a classic long-life blessing that turns literal when the machine's replacement parts were discontinued years ago, so the life it already has is the one it will keep.

## How to run

```bash
python3 main.py
```

This creates `/output` if needed and writes the fortune exactly to `/output/entry.txt`, printing nothing else.
